# Folha de marca — Biela

**Biela** é a loja de peças e acessórios de bike para quem pedala todo dia e quer manter a bicicleta
rodando redonda.

## Paleta

| Papel | Cor | Hex |
| --- | --- | --- |
| Primária (verde floresta) | ■ | `#0F5C47` |
| Primária escura | ■ | `#0A4332` |
| Destaque (laranja sinaleiro) | ■ | `#FF6B2C` |
| Fundo (concreto quente) | ■ | `#F4F1EA` |
| Texto | ■ | `#14231C` |
| Texto secundário | ■ | `#6B7A72` |
| Bordas | ■ | `#E1DCCF` |
| Sucesso / Alerta / Erro | ■ | `#1F8A4C` / `#8A6100` / `#C23B22` |

Verde para estrutura e navegação; laranja só para preço e ações de compra.

## Tipografia

**Space Grotesk** (Bold para títulos e preços, Medium para rótulos), via `@expo-google-fonts/space-grotesk`.
Texto corrido na fonte do sistema para leitura confortável.

## Ícone e abertura

Roda de bicicleta estilizada (aro laranja, raios claros) sobre verde floresta. Arquivos em `assets/`
(`icon.png`, `adaptive-icon.png`, `splash.png`).
